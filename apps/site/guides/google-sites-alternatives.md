Google Sites is the fastest way to put a page online if you already work in Google. You build it with your Google account, drop in Docs, Sheets and Forms, and publish. The trouble starts when the site needs to do more than show those files. Code only goes in through embed boxes. A custom domain needs a subdomain such as www. And there is no plan to upgrade to.

This guide is for two kinds of readers. Teams leaving Google Sites for a better public site or a better internal wiki. And people who can produce plain HTML, by hand or with a coding agent, and want a place to host it. We group the alternatives by job, not in one long ranking. We read every price on each vendor's own page on 25 November 2026.

![Google's help page "Use a custom domain for your site", with the steps to connect a domain to a site in Google Sites.](/guides/google-sites-alternatives/google-sites-domain.jpg "Google Sites help: use a custom domain, 25 November 2026")

## TL;DR

- **You or a coding agent can write the HTML:** Static.app, $60 a year for 2 sites with custom domains and forms. Cloudflare Pages and GitHub Pages are free, with limits.
- **You want a one-page site for the least money:** Carrd, $19 a year with a custom domain.
- **You want a designed, multi-page site without code:** Siter, from $7 a month billed yearly, or Squarespace, from €12 a month billed yearly.
- **Your Google Site was really a team wiki:** Notion Sites. Publishing to a notion.site address is free.
- **You need a CMS for a blog or a growing set of pages:** Webflow, from $15 a month per site billed yearly, CMS from $25.
- **You want motion and a design-tool feel:** Framer, from €10 a month billed yearly.

## What Google Sites does, and where it stops

Google's own help pages set out what it can do:

- **Custom domains.** You can connect up to five custom domains to one site. Only the site's owner can connect one. The address must include a subdomain, like "www". Work and school accounts go through their administrator.
- **Custom code.** You can add HTML, CSS or JavaScript through Insert, then Embed, or as a full page embed. JavaScript must sit inside `<script>` tags and CSS inside `<style>` tags. The code lives in its embed box. It does not change the rest of the page.
- **Analytics.** You paste a Google Analytics property ID into Settings. Google notes that renaming a page or giving it a custom path creates a new URL, which can affect tracking.
- **Export.** Google Takeout includes draft and published sites, custom page paths, navigation, themes, and site content such as text, images, links and embedded HTML. Google doesn't say on that page which file format you get, so check the download before you plan a migration around it.

What it doesn't list: a blog, a store, member logins, or any paid tier with more features. If you need one of those, you need another tool.

## If you can write HTML, or a coding agent can

Google Sites only lets your code into embed boxes. If you can produce a whole page as HTML, CSS and JavaScript, a static host gives that page the full browser window and your own domain.

### 1. Static.app: best for HTML you already have

[Static.app](https://static.app/) hosts static sites. You upload a folder or a ZIP and the site goes live with SSL. There is no Git setup and no build step.

![Static.app's pricing page with the 7-day free trial and the Starter plan at $5 a month, $60 billed annually.](/guides/google-sites-alternatives/static-app.jpg "Static.app's pricing page, billed annually, 25 November 2026")

**Pricing:** Starter is $60 a year for 2 sites and 500 MB, with custom domains, analytics and forms. Medium is $120 a year for 7 sites. Large is $180 a year for 30 sites. Billed monthly, each plan costs $12, $24 or $36 more a year. There is a 7-day free trial with no card, for one site on a free subdomain.

**Limitations:** no visual editor. No server code or database. 500 MB on Starter is tight for a site full of photos. No free plan after the trial.

**Good for:** anyone who has the HTML and wants it online on their own domain in a few minutes. [Put an agent-built page online, then check the live address](/guides/publish-and-check-live-page/) walks through the steps.

### 2. Cloudflare Pages: best free host if you use Git

[Cloudflare Pages](https://pages.cloudflare.com/) serves static sites from Cloudflare's network. You deploy from a Git repository or from its command-line tool. Cloudflare's limits page lists 500 builds a month on the free plan.

**Pricing:** free for most small sites. [Cloudflare Pages pricing in 2026](/guides/cloudflare-pages-pricing/) covers the paid limits.

**Limitations:** you work in Cloudflare's dashboard or a terminal. There is no page editor.

**Good for:** developers who already keep the site in a Git repository.

### 3. GitHub Pages: best free home for a personal or project site

[GitHub Pages](https://pages.github.com/) publishes a site straight from a GitHub repository.

**Pricing:** free for public repositories on GitHub Free.

**Limitations:** GitHub's docs say Pages is not intended or allowed for running an online business or ecommerce site. A published site can be at most 1 GB, with a soft bandwidth limit of 100 GB a month.

**Good for:** a personal page, a class or club site, or documentation for an open-source project.

## If you want to keep building visually

### 4. Carrd: cheapest for a one-page site

[Carrd](https://carrd.co/) builds one-page sites: a profile, a landing page, a link page.

**Pricing:** the free plan publishes up to 3 sites with "Made with Carrd" branding. Pro Lite is $9 a year for 3 sites, without custom domains. Pro Standard is $19 a year for 10 sites, with custom domains and forms. Pro Plus is $49 a year for 25 sites. Pro plans can embed your own code and widgets. [Carrd pricing in 2026](/guides/carrd-pricing/) has every tier.

**Limitations:** one page per site.

**Good for:** a Google Site that was really a single page of links and contact details.

### 5. Siter: best for a designed multi-page site

[Siter](https://siter.io/) is a visual website builder with a Figma plugin, so you can bring a design across from Figma.

![Siter's pricing page billed yearly, with Solo at $7, Plus at $12 and Pro at $24 a month, and Download HTML listed on Pro.](/guides/google-sites-alternatives/siter.jpg "Siter's pricing page, billed yearly, 25 November 2026")

**Pricing:** Solo is $7 a month billed yearly, or $8 month to month, for 1 site, 10 pages and 3 forms. Plus is $12 a month billed yearly, or $14, for 3 sites and 50 pages. Pro is $24 a month billed yearly, or $28, for 5 sites with unlimited pages and forms, and it adds Download HTML. Extra sites cost $4, $6 or $8 a month by plan.

**Limitations:** no free plan. Every plan starts with a 3-day trial that needs a card. Pages are capped on Solo and Plus. Its pricing page lists no store and no blog. HTML download is on Pro only.

**Good for:** a small business or designer who wants a site that doesn't look like a template, with forms, and a way to take the files later.

### 6. Squarespace: best all-in-one with a store

[Squarespace](https://www.squarespace.com/) builds and hosts template-based sites, with selling built in.

![Squarespace's pricing page with annual billing selected, showing the Basic plan at €12 a month.](/guides/google-sites-alternatives/squarespace.jpg "Squarespace's pricing page, paid annually, prices in euros, 25 November 2026")

**Pricing:** in euros for our location: €12, €18, €32 and €69 a month, paid annually. Each plan lists a free custom domain, marked with a footnote. The Basic plan charges a 2% fee on online store sales. There is a 14-day free trial.

**Limitations:** no free plan. Prices showed only in euros for us. You work inside Squarespace's templates and sections.

**Good for:** a business that wants a polished site and a small shop from one bill.

## If your Google Site was a team wiki

### 7. Notion Sites: best for internal docs made public

[Notion](https://www.notion.com/) can publish any page as a website. If your team already keeps its handbook or docs in Notion, that page can become the site.

![Notion's pricing page with yearly billing, showing Free at €0 and Plus at €9.50 per seat a month.](/guides/google-sites-alternatives/notion.jpg "Notion's pricing page, yearly billing, prices in euros, 25 November 2026")

**Pricing:** the Free plan includes basic sites on notion.site domains. Plus is €9.50 per seat a month with yearly billing, and adds custom sites. Custom domains are paid per domain. The pricing page doesn't show the per-domain price, so check it in Notion before you plan on one.

**Limitations:** it looks like Notion. Layout control is limited compared with a site builder. Prices showed only in euros for us.

**Good for:** a team handbook, onboarding pages or public docs that the team already edits in Notion.

## If you need a CMS or more design control

### 8. Webflow and Framer

[Webflow](https://webflow.com/) is a visual builder with a CMS for collections such as blog posts or case studies. [Framer](https://www.framer.com/) is a design-led builder known for animation.

![Webflow's pricing page billed yearly, with Starter free, Basic at $15 and Premium at $25 a month.](/guides/google-sites-alternatives/webflow.jpg "Webflow's site plans, billed yearly, 25 November 2026")

**Webflow pricing:** Starter is free on a webflow.io domain, with 2 static pages. Basic is $15 a month per site billed yearly, with a custom domain and 300 static pages, but no CMS. Premium is $25 a month per site billed yearly and adds the Webflow CMS. Prices are per site.

![Framer's pricing page with yearly billing, showing Free at €0, Basic at €10 and Pro at €30 a month.](/guides/google-sites-alternatives/framer.jpg "Framer's pricing page, yearly billing, prices in euros, 25 November 2026")

**Framer pricing:** in euros for our location, billed yearly: Free on a Framer domain, Basic €10 a month and Pro €30 a month, both with a custom domain. Site redirects come with Pro, which matters if you are moving pages from Google Sites.

**Limitations:** both take longer to learn than Google Sites. Webflow's CMS starts on the second paid plan. Framer has no built-in HTML export; [how to leave Framer](/guides/leave-framer/) covers what does come out.

**Good for:** a marketing site that will grow, made by someone who enjoys design tools. For editors you can host yourself, see [open-source Webflow and Framer alternatives](/guides/open-source-webflow-framer-alternatives/).

## Moving off Google Sites

1. **Export first.** Use Google Takeout to download your sites. Google says the export includes published sites, page paths, navigation, themes and site content, including embedded HTML. Open the download and check what you got before you rebuild.
2. **List every URL.** Write down each page's path, including any custom paths you set. You will need them for redirects.
3. **Rebuild the pages.** In a builder, paste in the text and images. For a static site, recreate each page as HTML. A coding agent can turn exported content into pages quickly, but check the result against the old site.
4. **Replace the Google pieces.** If the new tool takes embeds, publicly shared Docs, Sheets and Forms can come along as embeds. Swap them for native pages where you can.
5. **Keep or redirect each URL.** Use the same paths on the new site, or add 301 redirects from the old ones. On Framer, redirects need Pro.
6. **Move the domain.** In Google Sites, open Settings, then Custom domains, and remove the domain. Then point its DNS records at the new host, using the host's instructions.
7. **Check the live site.** Open each old URL and confirm it lands on the right page.

## FAQ

### Is there a free alternative to Google Sites?

Yes. Cloudflare Pages and GitHub Pages host static sites for free, with limits. Carrd's free plan publishes up to 3 one-page sites with its branding. Notion publishes pages to a notion.site address for free. Webflow's Starter plan is free for 2 pages on a webflow.io domain.

### Can I use my own domain on Google Sites?

Yes. Only the site's owner can connect one, and the address must include a subdomain such as www. You can connect up to five custom domains to one site. Work and school accounts need their administrator.

### Can I add my own code to Google Sites?

Only inside embeds. You can insert HTML, CSS and JavaScript as an embed or as a full page embed. The code stays in that box and doesn't change the rest of the page. For full control of the page, use a static host.

### Does Google Sites have a blog?

Google's help pages don't list a blog feature. If you need posts, look at Webflow's CMS, Squarespace, or a static site generator on a static host.

### How do I export my site from Google Sites?

Use Google Takeout. Google says the export includes draft and published sites, page paths, navigation, themes and site content, including embedded HTML. It doesn't say which file format you get, so download it and check before you plan the move.
