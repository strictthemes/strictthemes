# Security

## Report a problem

Please report a security problem in private, not in a public issue.

On this repository's page, open the **Security** tab and choose
**Report a vulnerability**. That opens a private report only the maintainers
can read. Say what you found, how to reproduce it, and which version or
commit it is in.

We aim to answer within a week. If the problem is real, we fix it,
publish a new version, and credit you in the release notes unless you would
rather not be named.

## What is covered

- The packages published from this repository: `@strictthemes/spec` and
  `@strictthemes/check`. Only the latest version of each gets fixes.
- The site strictthemes.com and the registry it serves at `/r`.

Strict Check opens the pages it is given in a headless browser and reads the
files of the project it is pointed at. It does not send them anywhere. A
report that shows otherwise is exactly what we want to hear about.
